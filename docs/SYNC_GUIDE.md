# 💎 คู่มือการทำงานของ Z-Sync (Synchronization Guide)

ทำความเข้าใจระบบการเชื่อมต่อ 2 ทิศทาง (Two-Way Sync) เพื่อการทำงานที่มีประสิทธิภาพและลดข้อผิดพลาด

---

## 🚀 ระบบ Auto-Sync (คอมพิวเตอร์ -> Roblox)
ระบบนี้จะทำงานแบบ **อัตโนมัติ (Real-Time)** ทันทีที่คุณเปิดปลั๊กอิน

### การทำงาน:
- เมื่อคุณ **เซฟไฟล์**, **สร้างไฟล์ใหม่**, หรือ **เปลี่ยนชื่อไฟล์** ใน VS Code หรือโฟลเดอร์โปรเจกต์
- เซิร์ฟเวอร์จะส่งข้อมูลไปบอกปลั๊กอินใน Roblox Studio ทันที
- ปลั๊กอินจะทำการอัปเดตสคริปต์หรือสร้างไอเทมใหม่ในเกมตามที่คุณสั่ง

### ข้อควรระวัง:
- ระบบนี้เน้นให้คอมพิวเตอร์เป็น **"ตัวหลัก"** (Source of Truth) ในการจัดการไฟล์สคริปต์และโครงสร้าง

---

## 📤 ระบบ Push (Roblox -> คอมพิวเตอร์)
ระบบนี้ทำงานแบบ **Manual (กดปุ่มเอง)** เพื่อความปลอดภัยของข้อมูล

### ทำไมต้องกดเอง? (สำคัญมาก!):
ในเวอร์ชันก่อนหน้า เราใช้ระบบ Auto-Push (ส่งข้อมูลอัตโนมัติ) แต่พบปัญหา **"ข้อมูลตีกัน"** (Race Condition):
1. หากคุณเปลี่ยนชื่อไฟล์ในคอม แต่ในเกมยังเป็นชื่อเก่าอยู่
2. ระบบ Auto-Push จะส่งชื่อเก่ากลับไปทับชื่อใหม่ในคอมทันที ทำให้ไฟล์ที่คุณอัปเดตหายไป!

### การทำงานที่ถูกต้อง:
- เมื่อคุณสร้างโมเดล, วางพาร์ท (Part), หรือตกแต่งแมพใน Roblox Studio จนพอใจแล้ว
- ให้กดปุ่ม **[Push]** บนแถบเครื่องมือ Z-Sync 1 ครั้ง
- ระบบจะดึงข้อมูลล่าสุดจากในเกม ลงไปบันทึกเป็นไฟล์ในคอมพิวเตอร์ให้เอง

---

## 💡 สรุปขั้นตอนการทำงานที่ดีที่สุด (Best Practice)
1. **งานเขียนโค้ด**: แก้ไขใน VS Code ได้เลย ระบบจะอัปเดตเข้าเกมให้เอง (ไม่ต้องกดอะไร)
2. **งานสร้างแมพ**: สร้างใน Roblox Studio ให้เสร็จ แล้วค่อยกดปุ่ม **[Push]** เพื่อสำรองข้อมูลลงคอม
3. **การเปลี่ยนชื่อ**: หากต้องการเปลี่ยนชื่อสคริปต์หรือโฟลเดอร์ แนะนำให้เปลี่ยนที่ **ฝั่งคอมพิวเตอร์** จะเสถียรที่สุด
