# 🚀 คู่มือการใช้งาน Roblox ZXD44 Bridge v2.0

ยินดีต้อนรับสู่ระบบเชื่อมต่อ Roblox Studio เข้ากับโลกภายนอก! ระบบนี้จะช่วยให้คุณสามารถจัดการแมพและเขียนโค้ดผ่านโปรแกรมภายนอก (เช่น VS Code) ได้แบบ Real-time

---

## 🛠 วิธีการเริ่มต้นใช้งาน

1. **รัน Server**: ดับเบิลคลิกไฟล์ `run.bat`
2. **เลือกโปรเจกต์**: พิมพ์ชื่อแมพที่คุณต้องการ (เช่น `MyGame`) แล้วกด Enter
3. **เปิด Roblox Studio**: เข้าไปที่แมพของคุณ
4. **ตั้งค่าความปลอดภัย**: ไปที่ `Game Settings` > `Security` > เปิด **Allow HTTP Requests**
5. **เริ่มใช้งานปลั๊กอิน**: ไปที่แถบ `Plugins` > มองหาหมวด `ZXD44 Bridge`

---

## 🕹 คำอธิบายปุ่มกด (Plugin Buttons)

### 1. 📤 Push Map
*   **หน้าที่**: ส่งข้อมูล "ทุกอย่าง" ในเกม ณ ตอนนั้น (Workspace, Scripts, GUI, Lighting ฯลฯ) ไปบันทึกเป็นไฟล์ในคอมพิวเตอร์
*   **ผลลัพธ์**: ไฟล์จะไปปรากฏที่โฟลเดอร์ `projects/[ชื่อโปรเจกต์]/src/`
*   **ใช้ตอนไหน**: ใช้เมื่อต้องการสำรองข้อมูลแมพลงคอม หรือต้องการเริ่มโปรเจกต์ใหม่

### 2. 🔄 Auto-Push
*   **หน้าที่**: เหมือนปุ่ม Push Map แต่ระบบจะทำให้เองอัตโนมัติทุกๆ 5 วินาที
*   **ใช้ตอนไหน**: เปิดทิ้งไว้เพื่อให้ไฟล์บนคอมพิวเตอร์ "สดใหม่" ตรงกับในเกมตลอดเวลาโดยไม่ต้องคอยกดเอง

### 3. 👂 Toggle Sync (Two-Way Sync)
*   **หน้าที่**: เปิดระบบ "หูทิพย์" เพื่อรับการเปลี่ยนแปลงจากคอมพิวเตอร์กลับเข้าสู่เกม
*   **ใช้ตอนไหน**: เปิดเมื่อคุณต้องการแก้ไขโค้ด `.lua` หรือค่าพลังในไฟล์ `.json` ผ่าน VS Code แล้วต้องการให้ใน Roblox Studio อัปเดตตามทันทีที่กด Save

### 4. 🔍 Server Status
*   **หน้าที่**: ตรวจสอบสถานะการเชื่อมต่อ
*   **ผลลัพธ์**: จะแสดงชื่อโปรเจกต์ปัจจุบัน, ที่อยู่โฟลเดอร์บนคอม และเช็คว่า Server ยังรันอยู่หรือไม่ในช่อง Output

## 📂 โครงสร้างไฟล์บนคอมพิวเตอร์ (Project Structure)

เมื่อคุณกด Push ข้อมูลจะถูกแยกออกมาดังนี้:

*   **โฟลเดอร์ `Workspace/`**: เก็บ Object ต่างๆ ในฉาก (Part, Model, Mesh)
*   **ไฟล์ `.lua`**: สำหรับ Script, LocalScript และ ModuleScript (คุณสามารถเปิดแก้ใน VS Code ได้เลย)
*   **ไฟล์ `.json`**: เก็บคุณสมบัติ (Properties) ของ Object เช่น สี, ขนาด, ตำแหน่ง, ความโปร่งใส
*   **โฟลเดอร์ `actions/`**: สำหรับส่งคำสั่งพิเศษจาก AI หรือโปรแกรมอื่นเข้าไปในเกม

---

## 💡 เคล็ดลับการใช้งาน (Two-Way Sync)

หากคุณต้องการแก้โค้ดจากข้างนอก:
1. เปิดไฟล์สคริปต์ที่ต้องการใน `projects/[ชื่อ]/src/ServerScriptService/...`
2. เปิดปุ่ม **Toggle Sync** ใน Roblox Studio ไว้
3. แก้ไขโค้ดใน VS Code แล้วกด **Save (Ctrl+S)**
4. โค้ดใน Roblox Studio จะถูกเปลี่ยนตามทันที!
