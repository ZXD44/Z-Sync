# 🏆 แนวทางปฏิบัติที่ดีที่สุด (Best Practices) สำหรับ Z-Sync

การจัดระเบียบโปรเจกต์จะช่วยให้การทำงานร่วมกันระหว่าง **Roblox Studio** และ **VS Code** ลื่นไหลที่สุด และป้องกันคอมพิวเตอร์ทำงานหนักเกินความจำเป็น

---

## 1. 📁 การจัดกลุ่มไอเทม (Grouping)
ปัญหาหลักที่ทำให้หน้าต่าง VS Code รก คือการปล่อยให้ชิ้นส่วน (Parts/Meshes) วางกระจัดกระจายอยู่ใน `Workspace` 

**❌ แบบที่ควรหลีกเลี่ยง:**
Workspace
 ├── Mesh_AlpTrees4
 ├── Mesh_AlpTrees4
 ├── Mesh_AlpTrees4
 └── Mesh_AlpTrees4

เมื่อคุณกด **Push** ระบบจะสร้างไฟล์ `.json` เป็นร้อยๆ ไฟล์ในคอมพิวเตอร์ของคุณ

**✅ แบบที่แนะนำ (Best Practice):**
ในหน้าต่าง Roblox Studio ให้คุณ:
1. เลือกต้นไม้ หรือพาร์ทประเภทเดียวกันทั้งหมด
2. กด `Ctrl + G` (Group as Model) หรือคลิกขวาเลือก **Group as Folder**
3. ตั้งชื่อโฟลเดอร์นั้นให้ชัดเจน เช่น `Environment_Trees`

Workspace
 └── Environment_Trees
      ├── Tree_1
      ├── Tree_2
      └── Tree_3

**ข้อดี:** ในฝั่ง VS Code จะถูกจัดเก็บเป็น 1 โฟลเดอร์ที่เป็นระเบียบ (ซ่อนไฟล์ยิบย่อยไว้ข้างในได้) ทำให้โปรเจกต์ดูเป็นมืออาชีพและจัดการง่ายมากครับ

---

## 2. 🚫 การใช้ระบบ Ignore (.syncignore)
อย่าลืมว่าคุณสามารถบอก Z-Sync ได้ว่า **"ไม่ต้องสนใจโฟลเดอร์ไหน"** 

**ตัวอย่างสถานการณ์:** 
คุณมีโฟลเดอร์ `Environment_Trees` ที่มีต้นไม้ 5,000 ต้น ซึ่งมันเสร็จสมบูรณ์แล้ว ไม่ต้องแก้ไขโค้ดอะไรข้างในอีก
- **วิธีทำ:** ให้เปิดไฟล์ `.syncignore` ในโปรเจกต์ แล้วพิมพ์ชื่อ `Environment_Trees` ลงไป
- **ผลลัพธ์:** ครั้งต่อไปที่คุณกด **Push All** ระบบจะข้ามต้นไม้ 5,000 ต้นนี้ไปเลย ทำให้เซฟลงคอมได้เร็วขึ้น 100 เท่า!

---

## 3. ⚡ การเลือกปุ่ม Push ให้ถูกจังหวะ
- **[Push Scripts]**: กดบ่อยๆ ได้เลยเมื่อแก้โค้ดเสร็จ (รวดเร็วมาก)
- **[Push All]**: กดเฉพาะตอนที่คุณสร้างโมเดลใหม่ วางฉากใหม่ หรือก่อนจะปิดโปรเจกต์เพื่อ Backup ข้อมูลทั้งหมดลงคอม
