# 💎 Z-Sync v2.0
> **ระบบเชื่อมต่อ Roblox Studio และเครื่องมือภายนอกที่ทรงพลังที่สุด**

พัฒนาโดย: **ZXD44** (Github)

---

## 🌟 จุดเด่นของระบบ
*   **Two-Way Synchronization**: แก้ไขสคริปต์ใน VS Code แล้วใน Roblox Studio เปลี่ยนตามทันที
*   **Project-Based**: แยกการจัดการแมพออกเป็นโปรเจกต์อิสระ ไม่ปนกัน
*   **Professional Architecture**: โครงสร้างไฟล์แบบมืออาชีพ แยกส่วนระบบและข้อมูลชัดเจน
*   **Thai Interface**: ข้อความแสดงผลและคู่มือเป็นภาษาไทยทั้งหมด ใช้งานง่าย

---

## 📂 โครงสร้างระบบ (System Structure)
*   `bin/` - ไฟล์สำหรับรันระบบ (`start.bat`)
*   `core/` - ระบบเซิร์ฟเวอร์หลัก (Node.js)
*   `studio/` - ปลั๊กอินสำหรับติดตั้งใน Roblox Studio
*   `projects/` - เก็บข้อมูลแมพแยกตามโปรเจกต์ที่คุณสร้าง
*   `docs/` - คู่มือการใช้งานเชิงลึก

---

## 🚀 เริ่มต้นใช้งานใน 3 ขั้นตอน

1.  **ติดตั้ง**: รัน `start.bat` ครั้งแรก ระบบจะติดตั้งปลั๊กอินเข้า Studio ให้โดยอัตโนมัติ
2.  **ตั้งชื่อ**: ระบุชื่อแมพ/โปรเจกต์ที่ต้องการจัดการ
3.  **เชื่อมต่อ**: ใน Roblox Studio กดปุ่ม **Push** เพื่อส่งข้อมูลมาที่คอม และเปิด **Sync** เพื่อเริ่มการพัฒนา!
